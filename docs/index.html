Features

📝 Custom DSL

Write diagrams in a simple, readable text format with syntax highlighting and auto-compile.

🎨 Visual Editor

Drag-and-drop nodes, draw connections, resize, style — full visual editing without touching code.

🔷 Code Generation

Export class diagrams to TypeScript or Java. Import .ts/.java files to auto-generate diagrams.

📐 Auto Layout

6 layout algorithms: layered, force-directed, radial, grid, linear, and sequence-optimized.

🌙 Dark Mode

Full dark mode support for comfortable editing in any environment.

📥 Export Anywhere

Export as PNG, SVG, JSON, DSL, TypeScript, or Java. Copy to clipboard with one click.
